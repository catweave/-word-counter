# Word Counter

**Автор:** Нечаева Ксения Вительевна, М3113
**IDE:** Visual Studio Code

## Описание

Плагин показывает в статус-баре VS Code статистику по текущему файлу:
количество слов, строк и символов. Счётчик обновляется автоматически
при вводе текста, открытии и сохранении файла.

## Возможности

- Счётчик слов, строк и символов в статус-баре.
- Автоматическое обновление при вводе текста.
- Обновление при переключении файла и сохранении.
- Команда `Word Counter: Показать статистику` в палитре команд
  с подробной информацией во всплывающем уведомлении.

## Установка

1. Скачать `.vsix` из раздела Releases (или из корня репозитория).
2. В VS Code открыть панель Extensions → `...` → **Install from VSIX**.
